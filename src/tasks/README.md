# tasks/README.md — 課題を追加するには

このディレクトリに課題を1つ追加すると、練習画面のセレクトボックスに自動で
選択肢が増えます。`core/` の中身を変更する必要はありません。

## 1. 課題メニュー

好きなものを1つ選んで担当してください。迷ったら `docs/backlog.md` を見て、
他の人が選んでいないか確認してから決めてください。

**達成基準はどれを選んでも共通です。**

> 出題パターンを用意し、自分の作業ブランチを push して、
> そこで発行されるプレビューURLをブラウザで開き、実際に動くことを確認できれば完成。
> **main へのマージは含みません**（先生がまとめて取り込みます）。

### 1. 数字・記号打ち
- ひとことで言うと：電話番号やパスワードのような、数字とキーボード上の記号を打つ練習
- 出題イメージ：`090-1234-5678` / `3.14159` / `#1234`
- 出題数の目安：3パターン以上

### 2. プログラミング用語打ち
- ひとことで言うと：教室で習うプログラミングの単語や短いコードを打つ練習
- 出題イメージ：`for` `const` `function` `console.log()` `return true`
- 出題数の目安：5個以上

### 3. ことわざ・四字熟語打ち
- ひとことで言うと：日本語のことわざ・四字熟語をローマ字入力で打つ練習
- 出題イメージ：「石の上にも三年」「一石二鳥」
- 出題数の目安：3つ以上
- 気をつける点：「し」＝`shi`でも`si`でも正解にするなど、複数の打ち方を許す。
  長音（ー）・外来語のカタカナ表記はローマ字変換が未対応（`docs/known-issues.md`参照）

### 4. 英文（短い文）打ち
- ひとことで言うと：英語の短い文章を打つ練習
- 出題イメージ：`The quick brown fox jumps.`
- 出題数の目安：3文以上（句読点・大文字を含める）

### 5. 都道府県名打ち
- ひとことで言うと：47都道府県の名前をローマ字で打つ練習
- 出題イメージ：「東京都」「北海道」
- 出題数の目安：5つ以上

### 6. 慣用句・早口言葉打ち
- ひとことで言うと：リズムよく打てる言い回しを打つ練習
- 出題イメージ：「生麦生米生卵」「猫に小判」
- 出題数の目安：3つ以上

### 7. 好きなジャンル語句打ち
- ひとことで言うと：自分の好きなアニメ・ゲーム・スポーツ選手名などをローマ字/英語で打つ練習
- 出題イメージ：好きな作品のタイトルやキャラクター名
- 出題数の目安：5つ以上（他人が読んでも意味がわかる言葉を選ぶ）

### 8. 記号多めのコード風打ち
- ひとことで言うと：カッコ・セミコロン・矢印記号など、記号を多めに含む短いコード片を打つ練習
- 出題イメージ：`if (x > 0) { return x; }`
- 出題数の目安：3つ以上

### 9. オリジナル課題（自由に決める）
- ひとことで言うと：上のどれにも当てはまらない、自分で考えたテーマで課題を作る
- 決め方：「何を打つか」「なぜ楽しい・役立つか」を一言で説明できるテーマにする
- 出題数の目安：3つ以上（迷ったら先生に相談してから着手する）

## 2. 追加の手順

`src/tasks/touch-type/index.ts` をテンプレとして進めます。

### 2-1. コードを書く

1. `src/tasks/自分の課題名/` フォルダを作る
2. `index.ts` に `TypingTask` を1つ書く

```ts
import type { ChallengeUnit } from '../../core/types/challenge.ts'
import type { TypingTask } from '../../core/types/task.ts'
import { register } from '../../core/registry/registry.ts'

const units: ChallengeUnit[] = [
  { display: '090', accepted: ['090'] },
  { display: '-', accepted: ['-'] },
  // ...出題する分だけ続ける
]

export const myTask: TypingTask = {
  id: '自分の課題id', // 他の課題と重複しない名前にする
  label: '画面に表示される名前',
  generate: () => ({
    displayText: units.map((unit) => unit.display).join(''),
    units,
  }),
}

register(myTask)
```

3. `src/tasks/index.ts` に1行追記する

```ts
import './自分の課題名/index.ts'
```

### 2-2. ローカルで確認する

```bash
npm run dev
```

練習画面のセレクトボックスに自分の課題が出てくるので、選んで最後まで打てるか確認する。

### 2-3. ブランチに push してプレビューURLで確認する

```bash
git checkout -b feature/task-自分の課題名
git add src/tasks/自分の課題名 src/tasks/index.ts
git commit -m "feat: 課題「〇〇」を追加"
git push -u origin feature/task-自分の課題名
```

push すると GitHub 上に「Compare & pull request」の案内が出るので、
Pull Request を作成する（レビュー・main へのマージは先生が行う）。

PR画面、または Cloudflare のプレビューデプロイ一覧からプレビューURLを開き、
ブラウザで自分の課題を選んで最後まで打てることを確認する。

**これができれば完成です。** マージされるタイミングは待たなくて大丈夫です。
