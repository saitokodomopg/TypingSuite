# 1. Requirements — 課題3「ことわざ・四字熟語打ち」

## 目的

`src/tasks/README.md` の課題メニュー「3. ことわざ・四字熟語打ち」を実装する。
日本語のことわざ・四字熟語を、ローマ字入力で打つ練習モードを追加する。

現状の練習課題（`touch-type-fj` / `home-position-basic`）はどちらもキーそのものを
1文字＝1ユニットで出題するだけで、ひらがな→ローマ字変換エンジン
（`src/core/engine/romaji.ts` の `kanaToUnits`）を使う実課題がまだ存在しない。
今回が `kanaToUnits` を使った最初の実課題になる。

## やること

- `src/tasks/kotowaza-yojijukugo/index.ts` に `TypingTask` を1つ実装する
  - 出題対象：ことわざ3つ以上・四字熟語3つ以上（計6パターン以上）
  - 1回の `generate()` で、候補からランダムに1つ選んで出題する
    （`home-position-basic` と同じ方式）
  - 各出題は「見出し（漢字表記）」と「読み（ひらがな）」を持つ
    - `displayText`：漢字表記（例：「石の上にも三年」）→ 意味が分かるようカードの説明文に表示
    - `units`：読み（ひらがな）を `kanaToUnits()` に通した結果 → 実際に打つ対象はひらがな→ローマ字
  - ローマ字の複数打ちは `kanaToUnits` が既に対応済みのものをそのまま使う
    （例：「し」= `shi` / `si` 両方正解）
  - 長音（ー）・外来語のカタカナ表記を含む語句は選ばない
    （`docs/backlog.md`「いつかやりたい」に記載済みの `romaji.ts` 未対応事項に抵触するため）
- `src/tasks/index.ts` に登録用の import を1行追加する
- ローカルで `npm run dev` を起動し、セレクトボックスから選んで最後まで打てることを確認する
