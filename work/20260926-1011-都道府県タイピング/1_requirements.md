# 1. Requirements — 都道府県名打ちタスクの追加

## 目的

`src/tasks/README.md` の課題メニュー「5. 都道府県名打ち」を実装し、
生徒がローマ字入力で都道府県名を練習できるようにする。

## やること

- `src/tasks/prefecture/index.ts` を新規作成し、`TypingTask` を1つ実装する
  - 47都道府県すべて（名前＋ひらがな読み）をデータとして持つ
  - `generate()` は毎回、47件からランダムに重複なしで5件を選んで1つの課題にする
  - 各都道府県名の読みは `src/core/engine/romaji.ts` の `kanaToUnits()` で
    ローマ字入力の単位（`ChallengeUnit[]`）に変換する（複数の打ち方・撥音・促音は自動対応）
  - 5件分の読みをそのまま連結し、スペースキーなどの区切り入力は不要にする
  - `challenge.displayText` には都道府県名（漢字表記）を選ばれた5件分並べて表示し、
    「今から何を打つか」が読める形にする
- `src/tasks/index.ts` に1行追記して登録する
- `src/tasks/prefecture/` 配下に、5件抽選・区切り不要な連結・`kanaToUnits`連携が
  正しく動くことを確認する最小限のテストを追加する（既存 `index.test.ts` の書き方に合わせる）

## 受け入れ条件

- [x] `npm run dev` で練習画面のセレクトボックスに「都道府県名打ち」が表示される
- [x] 選択すると、47都道府県からランダムに5件選ばれた課題が出題される
      （再読み込み・リトライで毎回組み合わせが変わることを目視確認する）
- [x] 表示された都道府県名（漢字）どおりに、ローマ字を続けて最後まで打ち切れる
- [x] 「し」→`shi`/`si`など、複数の打ち方が許容される（`kanaToUnits`に準拠）
- [x] `npm run test` / `npm run typecheck` / `npm run lint` が通る

## やらないこと（スコープ外）

- 都道府県の県庁所在地・地方区分などの付随情報の出題
- 47都道府県の読みデータの47件を超える出題数の調整（要望が出たら `docs/backlog.md` へ）
- 長音（ー）を含む読みへの対応拡張（既存の `known-issues.md` の対象外課題のまま）
